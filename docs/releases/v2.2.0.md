# 上岸 v2.2.0

## 本次更新

- 新增“今日还债”：历史未完成待办保留原日期，可继续学习或完成；当天新增观看、专注和完成记录单列，不混入今日计划进度。
- 移除历史待办的顺延到今日和补记完成入口，统一使用正常执行与完成流程。
- 完善统计日期：日时段分布显示日期、周视图显示每天日期、月视图显示格内日号。
- 学习页和首页添加课程共用多选筛选：右滑打开、左滑取消，底部应用按钮固定可见；同类并集、跨类交集，应用后才过滤。
- 修复 App 个人 Bark、Web 个人催办 Bark 和后台系统 Bark 配置布局；系统 Bark 新增测试通知按钮。
- 手动 Bark 催办遵循收件人的免打扰时段：时段内发普通通知，时段外发重要通知。
- 统一移动端图标、启动图与后台品牌标识。

## 升级说明

- 升级前备份 SQLite 数据库及附件目录。服务首次启动自动执行 V007 日期快照迁移。
- 旧数据无法还原迁移前曾经顺延的原始日期；还债统计以迁移后保存的日期快照为准。
- 历史补记数据保留可读，但旧客户端提交补记或历史改期请求会被服务端拒绝，建议同步升级 App。

- Android APK：正式签名安装包。
- iOS IPA：未签名，需自行签名后安装。
