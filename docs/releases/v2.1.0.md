# 上岸 v2.1.0

## 更新内容

- App 心跳携带本项目内当前页面与活动快照，后台和督学端可查看；只保存最新状态，离线展示最后上报，不采集其他 App 活动。
- 修复横屏催办与软键盘布局；手动催办支持可选标题和附加说明，自动催办触发规则与原文保持不变。
- 学习课程库和首页选课支持左滑/按钮打开流派、人物、标签筛选面板，每类单选、跨类交集，应用后生效；支持搜索防抖、已选标签移除和一键清空。
- 固定首页、课程库、数据页及设置页指定头部，只滚动对应内容；窄屏和键盘场景做自适应处理。
- 新增个人 Bark 设置：每个用户维护自己的设备 Key，启用后替代该用户 Server 酱，不双发。
- 新增独立系统 Bark 配置，用于课程同步及备份异常，持续故障合并通知。
- Bark 默认使用“上岸”分组、critical 重要通知和点击打开 App；个人推送仅访问部署者允许的 HTTPS 源站，禁止重定向。催办网络外发放在数据库写事务之外。

## 升级与配置

从 v2.0.0 升级会自动追加 V004–V006 迁移，保留现有数据。升级前请备份 SQLite 和附件，不要清空数据目录。

个人 Bark 默认允许官方 `https://api.day.app`。自建服务需要部署者通过 `BARK_ALLOWED_ORIGINS` 加入可信 HTTPS 源站；多个源站以逗号分隔，端口需准确匹配。个人设置与后台系统设置的 Key 互不替代，不回显到浏览器或 App。

系统备份异常依赖新版 `infra/scripts/backup.sh` 写入数据目录的脱敏状态。服务端每分钟检查；数据目录自身无法写入时，仍需要外部运维监控发现备份失败。

## 安装包

Android APK 使用正式签名。iOS IPA 未签名，需要自行签名安装。服务端提供 Docker 镜像归档。

## 验证边界

本地执行相关窄测试、静态分析、迁移和真实启动健康检查；全量验证与平台构建由 GitHub CI 执行。自动化验证不替代真机通知接收、点击唤起及播放体验验收。
