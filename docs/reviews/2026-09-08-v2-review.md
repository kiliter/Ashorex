# V2 服务端与 App 代码审查记录

日期：2026-09-08。范围：相对 `22d3ffd` 的 V2 工作区；分支基于包含该提交的 `main`，覆盖服务端、Flutter App、管理后台及必要运行脚本。三个子代理分工审查后交叉复审，修复仅针对有具体触发场景和影响的缺陷。

## 规范审查

| 问题 | 修复 |
|---|---|
| 归档账号的旧 JWT、管理员 Session 仍可写入 | 认证和后台授权读取账号当前状态与角色 |
| 媒体源错误正文或 URL 内凭据可能回显 | 固定媒体错误响应，配置入口拒绝不支持协议和 URL 凭据 |
| Emby 请求无视配置超时；同步网络调用占用 SQLite 读事务 | 使用已配置超时，完整读取远端后以短事务映射并写入 |
| 默认日期使用设备日期 | 默认统计和待办日期由服务端用户时区决定，显式历史日期保留 |
| V2 附件仍沿用 V1 备份目录 | 备份和恢复改为 attachments/todo_attachments，快照执行外键自检 |
| 干净 CI 缺少 YAML 解析依赖；后台独立变更不触发服务端验证 | 配置隔离的 PyYAML 环境并补充工作流路径 |

## 需求与行为审查

| 场景 | 修复 |
|---|---|
| 在用课程或用户直接彻底删除 | 删除前检查归档状态 |
| 已完成专注被再次操作而回退；手动完成仍占用运行槽位 | 终态拒绝继续操作，完成前保存本段时长并结束运行 |
| 通用进度接口重复累加专注时长 | 依据 ADR-0036，仅专用专注操作产生计时流水 |
| 课程自动达标绕过凭证，或完成时仍记录旧督学人 | 校验凭证并在首次完成时记录当前主督学人 |
| 顺延将旧观看时长带到新日期排行；同名课程或人物多角色混算 | 按实际观看事件窗口及课程 ID 聚合，人物姓名去重 |
| 催办跨日持续显示、回应重放覆盖历史、降级忽略用户配置及免打扰 | 按用户日期过期，回应幂等，降级遵循当前有效策略 |
| 重绑提交旧预览、未保存新父节点、暂时网络故障误判失联 | 预览与输入绑定、原位保存父来源，仅明确远端失联时隐藏 |
| 模糊映射抢占精确身份、多来源争用本地课时或歧义候选被下架 | 精确身份优先，拒绝自动争用，歧义候选保持原状待确认 |
| 下架课时仍可复用或顺延 | 服务端写入前校验资源可见性，App 去掉无效顺延入口 |
| 离线退出丢进度，删除事件阻塞其他课时 | 应用级持久队列保留原幂等键，由心跳恢复重放，明确已删 Todo 不阻塞后续 |
| 换账号复用缓存、迟到刷新覆盖新会话、迟到响应误删原账号队列 | 业务缓存按账号重建，请求、刷新与队列变更复核所属会话 |
| 历史 Todo 播放或专注误查今日；旧播放器命令影响重试后实例 | 路由携带日期，异步命令核对实例，后台失败仍停止计时并释放常亮 |

## 验证方式与边界

- 本地分别执行修改范围对应的服务端及 Flutter 窄测试，未执行模块全量测试，未禁用测试或降低关键断言。
- 管理后台构建与修改文件静态分析通过；统一格式化及差异检查在提交前执行。
- 使用独立临时数据库通过 `./run.sh server` 真实启动，健康端点为 `UP`；44 个业务 API 与运行时 OpenAPI 结构匹配。
- 在独立临时目录完成数据库与 V2 附件备份恢复检查，附件内容一致。未触及现有开发或生产数据库。
- GitHub PR 的检查结果是全量验证依据，不将本地窄测试等同于完整验收。
- 按用户要求未操作模拟器实播。此前原视频绿屏问题及 iPhone、iPad、Android 真机播放仍待人工验收，本次审查不宣称已经解决。
- V2 使用新数据库 baseline，不提供 V1 数据迁移；部署按 ADR-0031 先备份旧数据，再使用空数据目录。
