# 仓库内产品原型

本目录保存与冻结文档一致的原型快照，不依赖任何个人电脑绝对路径。

## 当前有效原型

- `shangan-v2-prototype.html` — 上岸 V2 唯一 UI 事实来源。

用浏览器直接打开即可查看，包含：

| 章节 | 内容 |
|---|---|
| 一 | 首页：目标看板、日 / 周 / 月视图、历史待办、删除说明 |
| 二 | 添加流程：课程（含目标进度）、专注计时、待办事项 |
| 三 | 执行与完成回填：播放页、全屏播放、专注运行、凭证必填 |
| 四 | 学习：按流派 / 按人物浏览、课程详情 |
| 五 | 数据：日 / 周 / 月统计、排行、热力图 |
| 六 | 我的：账号、考试目标、只读催办策略 |
| 七 | App 端心跳与催办承接 |
| 八 | 服务端 Web 管理后台（11 页） |
| 九 | 督学端 |

原型是评审与实现的依据；实现与原型不一致时，先确认是原型需要修还是实现需要改，不要各自漂移。

V1 的历史原型（AI 助教、旧版管理后台）已随 V2 重构删除，如需查阅请从 `v1-final` 标签的 Git 历史中获取。
