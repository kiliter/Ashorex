本课时目标

理解长期备考中“计划—执行—反馈—修正”的闭环，并区分记录进度与可信学习进度。

核心结论

  • 计划必须落到可完成、可验证的最小学习单元。
  • 视频播放位置只能表示媒体进度，不能直接证明学习完成。
  • 当日复盘只调整下一周期，不追求一次制定永久正确的计划。

关键术语

可信进度：由观看心跳、完成阈值和课后答题共同验证的学习结果。

学习债务：计划锁定后未按期完成、需要重新安排的学习项目。

复习提示

先确认“是否完成了正确的学习动作”，再讨论“今天学了多久”。
