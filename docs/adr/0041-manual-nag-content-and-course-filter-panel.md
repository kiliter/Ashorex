# ADR-0041：手动催办内容与课程筛选交互

- 状态：已批准（2026-09-08 用户确认按文档实现）
- 日期：2026-09-08
- 关联：ADR-0026、ADR-0027、ADR-0028；T13 / T17 / T22 / T24 / T27 / T28 / T30 / T31。

## 与现有冻结范围的差异

现有催办只有 message，没有独立标题；原型课程筛选把全部候选直接平铺在页面。新增标题协议与侧边筛选面板需要同步冻结文档和原型。

## 最小变更

1. 自动催办标题、文案、投递条件和渠道保持原行为。后台和督学手动催办新增可选标题（最多 80 字），现有 message 作为附加说明（最多 1000 字）；空标题使用原默认标题，空说明使用原默认文案。标题随记录持久化并用于全屏催办和 Server 酱，历史记录无标题时兼容旧展示。追加 V005 迁移，不修改旧迁移。
2. 课程库左滑打开右侧筛选面板，右上角筛选按钮提供同等入口。面板按流派、人物、标签三个分类切换，候选标签独立滚动并可搜索；按现有协议每类单选、三类之间取交集，不改变 Emby 主数据。
3. 面板内先选择，点击“应用筛选”一次生效；取消不改变当前条件。页面原筛选区仅展示已选标签，可单独移除；一键清空标签和搜索词，保留当前分组方式。全部候选不再铺满课程页面。
4. 课程搜索采用 300 毫秒防抖；清空立即生效，离页取消未触发查询。课程库标题、搜索、分组与已选条件固定，只有课程结果滚动。
5. “添加到今日课程”的选择课程步骤复用相同三类筛选面板、防抖、已选标签和清空交互；选择条件保持独立，不污染学习 Tab。面板标题和筛选固定，只有课程列表滚动。
6. 首页固定日期/操作头、目标看板和列表之前的汇总控件，只滚动待办内容；编辑模式保留批量操作，周/月保留其视图操作。
7. 数据 Tab 仅固定“学习数据”标题行到日/周/月切换区域；指标、图表和明细均滚动。

## 验收

- 自动催办内容不变；后台/督学手动标题与说明经保存、全屏展示和 Server 酱发送保持一致；旧记录兼容、长度校验、权限和每日次数限制不变。
- 左滑和按钮均能打开；三类标签、应用/取消、移除、清空、无结果、长列表、键盘和小屏可操作；两个入口互不串条件。
- 快速输入只在停止输入后过滤/查询，取消定时器后不更新卸载页面；顶部控件滚动前后位置不变。
- 本地只运行相关窄测试；迁移后 clean 并真实启动健康检查；全量验证交 GitHub CI。

## 评审修正：小屏与键盘（2026-09-08）

- 筛选面板显式避让软键盘；横屏高度不足时把搜索和关闭入口合并一行，候选仍独立滚动、应用按钮保持可见。
- 首页可用高度不足 600pt 时日期切换采用可滚动弹层；目标区在小屏或目标超过三个时显示主目标倒计时与总数摘要，通过“管理”查看全部目标。汇总保持固定，只有待办内容滚动。
- 课程库与今日选课在横屏键盘下合并固定控件行；选课无结果提示也在列表滚动区内。课程库筛选元数据读取失败提供重试提示，重复点击不会叠开面板。
- 窄回归覆盖横屏键盘、无结果、九个目标、固定区坐标、搜索 300ms 防抖与清空立即生效。
