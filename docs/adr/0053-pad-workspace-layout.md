# ADR-0053：Pad 工作台布局以 ashorex-pad-v2 为事实来源

- 状态：已批准（2026-09-10 用户要求按 `ashorex-pad-v2.html` 高保真实现）
- 关联：ADR-0014、ADR-0044；原型 `docs/prototypes/ashorex-pad-v2.html`

## 冻结差异

手机 UI 仍以 `docs/prototypes/shangan-v2-prototype.html` 为准。Pad（整屏宽 ≥768 且高 ≥500）的首页、学习、数据、我的外壳改以 `ashorex-pad-v2.html` 的 `pad-mode` 为准。这不是新业务能力，只重排同一套 Todo / 课程 / 统计数据。

## 最小变更

1. 侧栏宽 84pt，顶部「岸」字标，选中项浅蓝底描边；Pad 模式右侧描边改为浅色发丝线。手机继续用底部导航。
2. 首页：四格指标通栏；左侧待办工作区；右侧考试目标倒计时 + 今日节奏。红色 FAB 改为页头「添加待办」。
3. 课程库：满宽紧凑课程墙。点选后从右侧覆盖展开 400pt 课时抽屉，课程墙不缩放、不重排；点击遮罩或关闭按钮收起。系统返回在抽屉打开时只关抽屉。
4. 数据页：四格指标 + 图表/排行双栏 + 计划执行 / 学习构成。数字只来自既有 StatsView。
5. 我的：内容最大宽度 780pt，不引入主从栏。
6. 播放页保持既有宽屏排版，本 ADR 不改播放协议。

## 不做

- 不新增 API、字段或状态机。
- 不把演示用的「备考进度 61%」写成真实进度。
- 不接入 AI、伴学对话或播放校验。
- 不改手机布局、筛选口径、完成判定。

## 实施与窄验收

- Flutter Widget 测试覆盖：Pad 侧栏、首页工作台、课程墙覆盖抽屉、数据页计划执行与学习构成。
- 手机窄测试（底栏、课程网格、首页筛选）保持原口径。
- 物理 iPad 视觉验收另行记录。
