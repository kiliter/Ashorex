# ADR-0019：学习 Tab 作战日历与首页作战单改版

- 状态：已接受（2026-09-03 人工批准）
- 日期：2026-09-03
- 补充：ADR-0011

## 背景（Context）

V1 学习 Tab 当前直接展示全部课程列表，首页则把「今日作战单」放在考试倒计时之前，并用「今日追赶中」重复展示课程进度压力。这与用户完成闭环的主路径不一致：课程选择已经集中在作战单编排区，首页更应先看到考试压力，再看到当天任务；学习 Tab 应承担按日查看和编排作战单，而不是再铺一层课程目录。

同时，用户需要按日历回看历史作战单、识别哪天已经完成、优先看到过去未完成的承诺。这些能力不能改写日终终态：历史日一旦结算就必须只读。

## 决策（Decision）

### 首页

- 卡片顺序为：考试倒计时与课程进度压力 → 今日作战单 → 学习欠债与其它学习数据。
- 删除独立的「今日追赶中」卡片；进度压力继续留在考试卡片内。
- 今日作战单展示当天任务列表、完成比例、欠债条目数和继续执行入口；样式以产品确认的任务列表卡片为准。
- 首页不提供课程目录。

### 学习 Tab

- 学习 Tab 根页改为作战日历，不再作为课程列表入口。
- 日历按月展示；完成日用绿点，历史欠债或未完成用红点，并显示当日课时数与计划时长。
- 点击某一天查看该日作战单。当天把欠债和今日任务放在同一张表。提供回到当天。月份切换只刷新日历格子。
- 今天及未来日期可编辑作战单；过去日期只读。未来日课时不能直接计为学习，需加入今日或临时播放。
- 课程列表不再作为 Tab 根页；课时和模拟考试仍只能从作战单编排区加入。课程详情路由保留，供播放和摘要使用。

### 编辑边界

- 用户时区下今天及未来、且尚未进入日终终态的作战单可以保存。
- `PUT /api/v1/plans/{date}` 若 `date` 早于当天，返回稳定错误码 `PLAN_DATE_NOT_EDITABLE`。
- 历史日只读，展示欠债标记，不能增删改项目。过去未完成的工作通过当天的 `DEBT_REPAYMENT` 偿还，不回写历史作战单。

### 展示分组

- 作战单项目仍按课程及课时固有顺序排列，不提供手动调序。
- 客户端可按课程分组展开/折叠；模拟考试继续排在课时之后，单独成组。
- 项目视图补充 `courseId`、`courseName`、`quizRequired`、`debtId`，供分组和欠债标记使用，不改变保存快照的业务身份。

### 日历查询

新增只读接口：

```text
GET /api/v1/plans?from={date}&to={date}
```

返回日期范围内已有作战单的状态摘要。起止日期必填，`from <= to`，跨度不超过 62 天。不返回无作战单的日期。客户端用该摘要绘制打勾和欠债标记，再用现有 `GET /api/v1/plans/{date}` 读取当日详情。

## 后果（Consequences）

- 学习 Tab 从课程浏览变为作战日历，课程发现路径收口到编排区，符合「课时只能从作战单编排区加入」。
- 历史作战单可回看，但不能改写日终结果和欠债账本。
- 首页去掉重复压力文案，考试倒计时成为首屏第一信息。
- 需要扩展作战单项目只读字段和一个月历摘要查询；不新增编辑历史日的写接口。

## 被否决的方案（Rejected Alternatives）

- 允许修改历史作战单：会破坏日终终态、欠债幂等和修订审计。
- 学习 Tab 同时保留课程列表和日历：V1 只保留一个学习主路径，课程选择已在编排区。
- 客户端按天循环请求整月 `GET /api/v1/plans/{date}`：请求过多，且空日期也会打满。
- 把专注计时重新绑回作战单：与 ADR-0011 冲突，截图中的专注任务不进入 V1 作战单项目类型。
