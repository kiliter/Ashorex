# ADR-0016：Emby 来源联想、批量建课与课程归档

- 状态：已接受
- 日期：2026-09-02
- 补充：ADR-0003、ADR-0015

## 背景（Context）

ADR-0015 已允许管理员选择顶层媒体库或手工填写 Series/Folder ID，但课程页直接铺开全部顶层媒体库会混入与学习无关的来源，也无法表达一个媒体库应该提供剧集、电影还是两者。管理员需要先在 Emby 集成配置中明确允许使用的媒体库，再从课程页选择这些媒体库下的具体剧集或电影。

现有课程管理还没有删除入口。直接物理删除课程会级联或阻断课时、可信进度、计划、欠债、题目、全文、摘要和内容任务，与“可信学习数据优先、可恢复”的项目原则冲突。

## 决策（Decision）

### 来源发现与联想

后台提供“配置媒体库范围 + 课程来源选择器”两层边界：

1. `/admin/settings/integrations` 允许绑定多个配置用户可见的顶层视频媒体库；每个绑定必须选择“剧集”“电影”或“混合”类型。
2. 课程页不铺开媒体库本身，也不要求管理员先输入关键字；点击“选择 Emby 课程”后，弹窗分页读取已绑定媒体库内符合绑定类型的全部 `Series` 或 `Movie`。
3. 候选项只返回名称、Emby Item ID、Item Type、Collection Type 和必要的父节点 ID；不返回原始媒体路径、主机或密钥。
4. 候选结果按名称和 Item ID 稳定排序并去重；弹窗内搜索只过滤已经加载的候选，最多可勾选 50 条。
5. 剧集/电影只是默认联想范围，不是后端来源类型硬限制。课程创建和重新绑定继续兼容媒体库、Series、Folder、Movie 与手工 Item ID；已有课程不受影响。

### 单个添加与批量添加

课程创建提供两种明确动作：

- “添加并同步”：选择一个来源，默认使用 Emby 名称作为课程名，创建课程后立即同步完整视频快照。
- “批量添加并同步”：把最多 50 个联想来源加入待添加列表，一次提交后为每个来源创建一门课程，并按选择顺序串行同步；服务端继续接受兼容来源类型。

批量提交前先验证全部来源仍存在且当前用户可访问，再用一个短事务创建或恢复课程；远端视频同步在事务外逐门串行执行。某门课程同步失败时保留已创建课程并记录安全错误，不回滚其他课程，页面按来源展示创建、恢复、跳过和同步失败结果。

相同 `emby_parent_item_id` 的活动课程不得重复创建；重复选择活动课程时幂等跳过。若相同来源对应已归档课程，则恢复原课程而不是创建新的本地课程身份。

### 已有课程映射

已有课程使用来源选择器选中目标后直接生成重新绑定预览。安全自动映射仍按 ADR-0015 执行；没有冲突时可一键确认，有冲突时仍必须逐项人工确认，联想选择不得绕过映射安全规则。

### 课程删除

后台“删除课程”定义为可恢复的逻辑归档：

- 将课程 `enabled` 设为 `false`，不物理删除课程、课时或任何学习历史。
- App 目录、计划新增选择和定时 Emby 同步忽略已归档课程。
- 后台默认列表隐藏已归档课程，并提供“已归档课程”视图和恢复操作。
- 删除确认页必须明确说明课时和学习历史会保留，并展示课程名称与课时数量。
- 恢复课程沿用原课程 ID、课时 ID 和全部历史关系；恢复后可手动同步。

本变更不新增或修改 `/api/v1` 学习端契约，只增加内部 ADMIN 页面和后台 JSON 联想端点。

## 后果（Consequences）

- 管理员点击按钮即可看到已绑定媒体库范围内的全部剧集或电影，不必先猜关键词，也不会在课程页铺开全部媒体库。
- 一组 Emby 课程目录可批量转为上岸课程，并得到逐项执行结果。
- 删除操作不会破坏可信学习历史，误删后可以恢复。
- 批量远端同步不是全有或全无；失败课程保留错误状态，便于单独重试。
- 弹窗首次打开会增加分页 Emby 元数据请求，但只在管理员主动点击后发生，限制在绑定媒体库和配置用户作用域内，且不暴露物理路径。

## 被否决的方案（Rejected Alternatives）

- 在浏览器直接调用 Emby：会把 Base URL 和 API Key 暴露给后台页面。
- 课程页常驻加载全部 Series/Movie：会无谓增加页面和服务端压力；本方案只在弹窗打开后分页加载。
- 物理删除课程及关联数据：会破坏学习历史、审计和欠债关系。
- 批量同步放进数据库事务：远端请求会长时间占用 SQLite 写事务。
- 发现歧义后自动选择第一个映射：可能把可信进度关联到错误视频。
