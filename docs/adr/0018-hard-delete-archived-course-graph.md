# ADR-0018：物理删除已归档课程及完整关联数据图

- 状态：已接受（2026-09-02 人工批准）
- 日期：2026-09-02
- 取代：ADR-0017 中“移除但保留历史、同来源恢复原身份”的决策
- 补充：ADR-0015、ADR-0016

## 背景（Context）

ADR-0017 将“删除已归档课程”实现为写入 `courses.removed_at` 后隐藏课程，课程、课时和学习历史仍保留。该语义不能减少错误同步产生的重复课时，也会导致管理员归档、删除并重新添加同一 Emby 来源后继续恢复旧课程身份。对于已经产生错误课时快照的课程，这相当于只删除了管理界面入口，没有删除管理员明确要求清理的数据。

管理员现已明确要求：从“已归档课程”区域确认删除后，物理删除课程以及所有直接或间接关联数据，不保留可恢复的旧课程身份。由于删除范围包含可信观看进度、计划、欠债、答题和报表派生数据，这是一项覆盖既有“可信学习数据优先”规则的破坏性范围变更，必须以明确的依赖图、二次确认和短事务约束实施。

## 决策（Decision）

### 删除资格与交互

- 只有 `enabled=false` 的已归档课程可以物理删除；活动课程必须先归档。
- 单个与批量删除均必须二次确认，批量最多 50 门。
- 确认弹窗必须明确显示课程数、课时数，以及计划项目、欠债、观看记录、答题记录、学习内容、内容任务等关联数据的实际统计；文案明确说明“删除后不可恢复，重新添加会创建全新课程”。
- 任一课程不存在、仍为活动状态或删除预览已经失效时，整批拒绝，不产生部分删除。
- 删除请求携带预览版本或等价校验信息，防止管理员确认后关联数量发生变化却仍按旧提示删除。

### 物理删除范围

删除服务按课程 ID 和其全部本地课时 ID 解析完整关联图，并物理删除：

1. 课程关系：考试目标课程绑定、课程移除审计、课程本身。
2. 课时与媒体关系：课时快照、Emby Item ID 映射审计、全文、Markdown 摘要。
3. 计划与欠债：直接引用课时的计划项目、由这些项目产生的欠债、偿还记录，以及引用这些欠债的还债计划项目。
4. 学习记录：观看会话、验活记录、可信视频进度、复习审计、与被删除计划项目关联的专注或模拟考试记录及其附件元数据和受控存储文件。
5. 题库与答题：正式题目、选项、答题尝试、答题明细，以及题目草稿对已发布题目的引用。
6. 内容生成：内容任务、阶段日志、题目草稿、草稿题目和草稿选项。
7. 派生与审计：包含被删除计划项目的作战单修订快照；受删除数据影响日期的日报快照和日终结果失效记录，由确定性报表和日终服务按剩余数据重新生成。

不删除与目标课程没有直接或间接关系的用户、考试目标、作战单容器、模拟考试预置、其他课程及其学习数据。一个作战单同时包含多个课程时，只删除目标课程相关项目；空作战单仍保留为当天业务容器。作战单修订快照包含完整 JSON，无法安全做局部外键级删除，因此删除受影响计划的历史修订并在需要时写入新的当前快照审计。

### 一致性与并发

- 应用服务负责事务，Repository 按明确的叶子到根顺序执行删除；Controller 不使用 `JdbcClient`。
- 不依赖现有 `ON DELETE CASCADE` 猜测删除范围；数据库外键继续作为遗漏保护。
- 数据库关联记录必须在一个短事务中全有或全无删除。受控附件文件先校验位于允许的数据目录，事务提交后删除；文件删除失败必须记录不含敏感路径的安全错误并进入可重试清理，不得恢复已删除数据库业务数据。
- 删除开始前终止或失效目标课程的活动观看会话和内容生成任务。Worker、心跳和重试入口必须在写入前重新确认目标仍存在，删除后不得重新创建课程关联数据。
- 删除预览和执行都不得输出 Emby 原始路径、密钥、全文、摘要或题目正文。

### 重新添加语义

课程物理删除后，相同 `emby_parent_item_id` 不再对应任何历史课程。管理员重新添加相同 Emby 来源时必须创建新的课程 UUID、新的课时 UUID 和全新的学习数据，不得从 `removed_at`、审计表或其他残留记录恢复旧身份。

## 后果（Consequences）

- 错误同步产生的重复课时可以通过归档并物理删除课程后彻底清理；重新添加后只按当前 Emby 数据建立新课程。
- 管理员会永久失去该课程的可信进度、计划关联、欠债、题目、答题、全文、摘要、生成任务和相关报表历史，因此确认页面必须展示真实影响数量。
- 既有 V027 `removed_at` 与移除审计仅作为历史兼容字段；新物理删除成功后对应课程行和审计行都不存在。
- 需要追加迁移或索引以支持安全统计与删除，但不得修改 V027 或其他已应用迁移。
- 报表和日终结果属于删除数据的确定性派生物，必须失效并按剩余数据重建，避免页面继续展示已删除课程贡献的时长或完成量。

## 被否决的方案（Rejected Alternatives）

- 继续只写 `removed_at`：不能清理错误课时，也会在重新添加时恢复错误历史。
- 只删除 `courses` 和 `media_items`：会被外键阻止，或在关闭外键时留下计划、欠债、答题和内容孤儿。
- 保留最小课程删除审计并引用旧课程 ID：仍属于课程关联数据，与“关联的都删除”不一致。
- 删除整个用户或整个作战单：会误删与目标课程无关的数据，超出管理员选择的课程范围。
- 仅依赖数据库级联：现有大量关系使用 `RESTRICT`，且 JSON 修订、派生报表和受控文件不受数据库级联完整覆盖。
