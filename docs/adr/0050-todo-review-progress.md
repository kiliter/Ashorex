# ADR-0050：当前待办复习确认与独立进度

- 状态：已接受，2026-09-10 用户确认。
- 范围：修订 ADR-0047 的已完成视频回放；当前 main 开发，保留其他待提交改动。

点击已完成课程「复习」先确认。确认才清零当前 Todo 的视频进度并开启新播放轮次；保留 DONE、完成时间、附件、备注和累计观看时长，不新增 Todo、不重新计完成次数、不进入未完成催办。课程库对应课时的历史进度不清零，仍按稳定 resourceId 累计最大进度与实际观看时长。

待办复习进度与课时历史隔离：本轮最远进度用于待办展示，独立恢复位置记住最近播放处；重新进入使用「继续复习」，只有明确选择「重新复习」并确认才再次重置。取消不请求、不修改、不进入播放器；重置失败不开始播放。

请求带 expectedPlaybackEpoch 和稳定 requestId，重复请求不重复重置，过期确认拒绝。进度上报增加可选 playbackEpoch，旧 App / 旧离线事件缺省为 0；旧轮次事件继续幂等记录真实时长，但不覆盖新轮次进度、恢复位置或完成状态。课时历史仍单调不回退。新 App 连接不支持重置的旧服务端提示升级服务端，不在本地假装重置成功。

数据库追加 V011，只新增列，不改已发布迁移。公开列表增加 playbackEpoch、resumePositionMs；进度请求新增可选字段，不删除原字段。首次普通待办保持原进度行为；复习后的旧 App 仍能播放及累计真实时长，但无法更新新轮次续播位置，需要新版才能使用本轮复习记忆功能。用户本次已确认该范围，既有学习、登录和离线队列继续可用。

验收：确认取消、确认成功与失败、重复重置幂等、过期确认、归属校验、旧轮次延迟上报、重新记忆及继续复习；保留 DONE/完成时间/历史时长及课时历史，新增真实观看时长只累计一次。迁移真实启动 UP，真实请求验证恢复位置与课时进度隔离；自动化不启动数据库，全量验证交 CI。
