# ADR-0029：所有实体统一走「归档 → 彻底删除」两阶段，并强制级联清理

- 状态：提议（待人工批准）
- 日期：2026-09-07
- 相关：取代 ADR-0017、ADR-0018、ADR-0023 的删除路径

## 背景

V1 的删除路径是分散演进出来的：课程曾用「归档」表达下线（ADR-0016），后来又改成移除归档概念并支持硬删除（ADR-0017、ADR-0018），用户删除是直接硬删（ADR-0023）。结果是同一个系统里存在两套语义，且每次新增关联表都要重新审一遍级联清理是否完整。

用户要求：课程、用户这类删除要完善级联，不能在数据库里留垃圾数据；删除逻辑改为先归档，然后在已归档里再删除。

## 决策

### 统一生命周期

```text
ACTIVE → ARCHIVED → 彻底删除
```

适用实体：课程、学习资源、用户、督学关系。

- 列表页**只提供「归档」**，不提供物理删除。
- 归档是可逆软状态：学习端不可见、不可新建引用（不能加入 Todo、不能登录），但历史统计仍可查。
- 彻底删除是**唯一**会执行物理 `DELETE` 的入口，只存在于后台「归档区」页面。
- 归档保留期默认 30 天，到期**只提醒，不自动删除**。数据销毁必须由人显式确认。

### 删除前预检

彻底删除前必须展示完整级联清单：涉及的表、预计行数、磁盘文件占用、受影响用户数与统计影响，并要求管理员**输入实体名称**二次确认。

### 级联顺序固定

课程：

```text
todo_attachments(+文件) → todo_progress_events → todo_deletions(引用该课程)
→ todos → lesson_watch_states → course_genres/tags/people
→ resource_source_mappings → learning_resources → courses → deletion_audits(+1)
```

用户：

```text
todo_attachments(+目录) → todo_progress_events → todos → todo_deletions
→ lesson_watch_states → exam_goals → nag_deliveries → nags
→ nag_policies(scope=USER) → supervisions(双向) → user_presence
→ refresh_tokens → user_roles → users → deletion_audits(+1)
```

- 全部在**单个事务**内完成，任一步失败整体回滚。
- 磁盘附件文件与数据库行在同一操作中清理；文件删除失败视为整体失败。
- 外键统一声明：指向 `users` 的用 `ON DELETE CASCADE` 兜底，指向 `courses` / `learning_resources` 的用 `ON DELETE RESTRICT`，强制显式按顺序清理，避免「以为级联删了其实没删」。

### 审计与自检

- 每次彻底删除写 `deletion_audits`：实体类型、ID、显示名、操作人、各表删除行数。**不保存被删内容明细**。
- 孤儿数据自检：每日备份后自动执行，后台可手动触发。检查项包括无主 `todos` / 进度事件 / 附件行、磁盘上无数据库行的附件文件、指向已删资源的 `lesson_watch_states`、指向已删用户的 `nags` / `supervisions`。
- 删除前要求「今日备份成功」为可配置前置条件。

## 后果

正面：

- 删除语义在整个系统里只有一套，新增关联表时只需更新一处级联顺序与自检项。
- 误删有 30 天缓冲；真正销毁需要两次显式动作。
- 孤儿自检把「有没有留垃圾」从人工审查变成可观测指标。

负面与代价：

- 每个实体多一个状态维度，列表查询与唯一约束都要考虑 `ARCHIVED`（例如唯一索引需带 `WHERE archived_at IS NULL`）。
- 级联顺序是硬编码知识，新增引用表时若忘记更新，孤儿自检才会发现。因此自检项必须与级联顺序同步维护，并在测试中断言顺序。
- 归档区可能长期堆积对象，需要保留期提醒来促使处理。

## 替代方案

1. **完全依赖数据库外键 `ON DELETE CASCADE`**。否决：SQLite 下难以观测删除范围，无法生成预检清单，且磁盘文件不会被级联清理。
2. **只做软删除，永不物理删除**。否决：用户明确要求不留垃圾数据，且附件会持续占用磁盘。
3. **保留 V1 的直接硬删 + 二次确认**。否决：误删不可恢复，且级联完整性靠人工审查。
