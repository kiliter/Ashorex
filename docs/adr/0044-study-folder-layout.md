# ADR-0044：学习页文件夹网格与看完筛选

- 状态：已批准（2026-09-09 用户确认实现）
- 关联：T05、T27；原型 4-1、4-2、4-3；ADR-0041。

## 冻结差异

原型使用横向大课程卡片，未提供全部看完过滤；课程详情整页滚动。本次请求改变以上 UI 与筛选口径，本稿已确认，替代相应原型布局。

## 最小变更

1. 学习 Tab 固定工具区增加“隐藏已看完”开关，默认关闭。可与关键词、流派、人物、标签叠加；开关仅影响学习 Tab，不污染今日添加课程。清空全部条件时关闭该开关。
2. 全部看完指当前可见视频课时非空、每个课时的累计最远位置达到有效总时长。无有效时长的课时不能判为看完，零课时课程不隐藏。手动完成或达到 30% 等 Todo 目标不能替代 100% 观看位置。沿用 V2 可拖动播放进度的规则，不引入可信播放。
3. 服务端 CourseSummary 新增 fullyWatched 字段，按既有跨 Todo 累计位置计算；Flutter 只消费服务端结论。旧 completedCount / completedPercent 保留原语义，不用于此开关。同步 OpenAPI 与 DTO，缺失新字段时客户端按 false 兼容。
4. 按流派视图改为文件夹网格：普通手机三列，小屏或大字体降为两列，平板按可用宽度增加列数。文件夹显示图标、最多两行课程名、“已完成 x/y 课时”，省略大封面、标签堆叠和累计时长。完整名称通过无障碍语义与详情提供。点击整个文件夹打开详情，触控区域不小于 44pt。
5. 保留按人物入口，人物也采用紧凑文件夹网格，显示姓名与课程数；点击沿用按该人物筛选课程的行为。网格按可见区域惰性构建，不预先构建所有课程组件。
6. 详情固定返回、课程摘要、搜索、继续/批量加入按钮和课时标题，只有剩余高度中的课时列表独立滚动并惰性构建。小屏、横屏及键盘出现时压缩摘要，保证课时区域有可用高度；空结果提示留在课时区域。

## 实施与窄验收

- 先写窄测试并确认失败，再实现服务端 fullyWatched 汇总与 Flutter 布局；不修改数据库。
- 服务端纯单元测试：全部达到末尾、部分达到、仅 Todo 完成、零课时、无有效时长；不启动数据库。
- Flutter Widget 测试：开关与已有筛选叠加、清空、空结果、人物入口、长名称/大字体/横屏无溢出；滚动课时后顶部坐标不变；大量课程与课时按需构建。
- 本地运行修改对应的窄测试和格式检查，全量验证留给 GitHub CI；设备视觉验收另行记录。

## 2026-09-09 已批准修正：参考片单的双列封面卡片

用户以参考截图明确纠正文件夹图标布局：学习页改为双列封面卡片，上方 1.6:1 课程封面，下方 12pt、最多两行课程标题及完成课时数；平板增加列数，系统大字体保留缩放。长按和无障碍提供完整名称。取消文件夹图标；真实图片通过认证的 `/api/v1/catalog/courses/{courseId}/cover` 获取，先校验课程可见性，复用 Emby 网关的类型、大小和超时限制，无封面时使用文字封面占位。人物卡片使用其首门课程封面。保持隐藏看完、过滤叠加与课时区域独立滚动。本节替代本 ADR 先前关于文件夹图标及手机三列的描述。


## 2026-09-09 已批准：横向分类栏与文字书封

在“全部课程 / 已选条件”下方固定横向可滚动分类栏，首项为“全部”；按流派时来自课程流派元数据，按人物时来自人物元数据，无元数据用“未分类 / 未标注人物”。点击分类直接筛选课程卡片，多流派课程可出现在多个分类；切换维度、一键清空均重置当前分类。分类与关键词、隐藏已看完、既有多选筛选取交集，分类栏自身横滑不触发筛选抽屉。下方统一显示课程卡片，不再显示人物目录卡或重复流派组标题。

无封面时采用深色文字书封：稳定的藏蓝 / 墨绿 / 暗紫 / 棕色配色、细书脊线、淡暗纹与浅色标题，明确区别于浅色页面背景；仍是纯文字封面，不引入生成图片。标题保持系统字号缩放，大字体时隐藏装饰小字。真实封面和筛选协议保持不变。


本轮验证：学习页和课程详情 20 项窄测试通过；已热重启 iPhone 17 Pro 模拟器，并检查横向分类栏和深色文字书封实际显示。本轮仅改 Flutter 与原型文档，无需后端变更。


## 2026-09-09 已批准修正：加入课时的完成标准固定

T24 / 原型 2-2：首页添加课程和课程详情共用的加入课时弹窗，只有课时内容纵向滚动并按需构建；课程标题、观看状态筛选、完成标准、已选汇总和加入按钮固定。空间不足时标准选项收为下拉、隐藏辅助预览，横屏左右分栏，自定义目标可在固定区输入。目标取值、预览防重与提交协议不变。

用户追加确认：课时区提供常显可拖动滚动条，4pt 圆角蓝色滑块、浅灰轨道，内容右侧留白 12pt；无溢出时不绘制无意义滑块。弹窗使用固定关闭按钮，省略额外拖拽柄以保证横屏键盘下可用高度。
