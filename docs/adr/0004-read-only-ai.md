# ADR-0004：AI 严格保持只读

- 状态：已接受
- 日期：2026-08-27

## 背景（Context）

AI 可以帮助用户理解计划、报表和课程视频，也可以通过联网搜索补充资料。但计划、欠债、可信进度和学习记录属于高可信业务数据，模型输出具有不确定性，不能成为这些数据的写入入口。

## 决策（Decision）

AI 只提供首页通用问答和视频页面问答两个入口。内部仅允许以下只读工具：

```text
get_today_plan_summary
get_open_debt_summary
get_exam_progress
get_daily_report
get_weekly_report
search_video_transcript
get_video_summary
```

联网搜索只通过固定 URL 的 MCP 服务，并仅向模型暴露显式白名单中的搜索类工具。AI 不得新增、修改或删除计划、欠债、考试目标、学习记录及其他业务数据。转写文本、网页和 MCP 返回均作为不可信上下文分隔处理，不能覆盖系统指令。

## 后果（Consequences）

- AI 能解释用户数据和视频内容，但不能代替确定性的业务状态机。
- 工具注册表和依赖边界必须通过自动化测试证明不存在写工具。
- Flutter 只负责聊天 UI、SSE 渲染和引用展示，模型运行、上下文和工具权限都在服务端。
- MCP 搜索失败时对话需要安全降级，不能影响核心学习功能。
- 报表和晚间审判继续由规则与 SQL 生成，不使用 AI。

## 被否决的方案（Rejected Alternatives）

- AI 自动制定或修改计划：模型错误可能破坏已锁定计划和用户信任。
- AI 自动核销欠债或标记学习完成：会绕过可信学习规则。
- 向模型开放数据库、文件系统或 Shell 工具：权限过大且存在数据与主机安全风险。
- 使用多智能体：超出 V1 范围，并增加权限和执行链路复杂度。
