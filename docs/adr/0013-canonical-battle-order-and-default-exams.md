# ADR-0013：作战单按课时固有顺序排列并提供默认考试预置

- 状态：已接受
- 日期：2026-09-01

## 背景

作战单选择器当前只能单向加入项目，误点后必须退出再删除；同时允许用户手动上下移动课时，容易打乱课程本身的学习顺序。模拟考试预置完全从空数据开始，也增加了首次使用成本。

## 决策

作战单选择器使用可切换选择：未选项目点击后加入，已选且未开始的项目再次点击后取消；已经开始的不可变项目继续禁止取消。

所有视频学习与复习快捷入口严格按照课程排序和课程内课时排序排列，客户端不展示手动上移或下移操作，服务端保存时忽略客户端提交的课时顺序并重新计算固有顺序。模拟考试排列在课时之后，同类模拟考试保留选择顺序。

系统为现有用户和以后新建用户幂等补齐三个可编辑、可删除的模拟考试预置：

- 行测：120 分钟，采用 2026 年度中央机关公务员公共科目笔试官方时限。
- 申论：180 分钟，采用 2026 年度中央机关公务员公共科目笔试官方时限。
- 大作文：180 分钟；大作文不是独立官方科目，该值采用产品约定的完整专项模拟时长。

用户删除或修改默认预置后，普通列表读取不自动重建；只有用户首次创建或数据库升级时执行一次默认初始化。

## 后果

- 作战单客户端草稿与服务端持久化结果使用同一课时固有顺序。
- 保存接口的 `sortOrder` 对课时不再构成业务真相，只用于兼容现有客户端；模拟考试的相对选择顺序仍可使用。
- 新建用户事务会调用显式的用户默认数据初始化接口，避免身份模块直接访问模拟考试表。
- V022 以追加式迁移为已有用户补齐缺失的默认预置，不覆盖同名数据。

## 被否决的方案

- 只在 Flutter 隐藏上下移动按钮：直接调用 API 仍可写入乱序数据，服务端结果不可信。
- 每次打开列表都在空列表时重建默认项：用户主动删空后会被重新创建，无法表达真实意图。
- 把大作文标记为官方独立科目：官方只规定整场申论 180 分钟；大作文 180 分钟是产品预置，不冒充官方独立科目时限。
