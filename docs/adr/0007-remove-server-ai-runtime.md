# ADR-0007：移除服务端 AI Runtime，课程内容改为管理员导入

- 状态：部分被 ADR-0008 替代
- 日期：2026-08-31
- 替代：ADR-0004
- 部分替代：ADR-0006

> 当前课程内容生产边界以 ADR-0008 为准；本文保留为 Task 19 的历史决策记录。

## 背景（Context）

V1 已实现服务端 LLM、ASR、MCP、自动转写、自动摘要和 Flutter AI 入口。当前产品方向要求服务端专注可信学习闭环，视频全文与 AI 摘要由独立流程生成后上传；移动端 AI 将来在 Flutter 侧单独设计。继续保留服务端 AI Runtime 会增加依赖、配置、密钥、运维和数据表，但不再为当前 V1 提供必要价值。

## 决策（Decision）

服务端完整删除 LLM、ASR、MCP、LangChain4j、AI Chat/SSE、FFmpeg 自动转写与自动摘要。Flutter 删除 AI Tab、视频 AI 弹层及相关客户端基础设施，底部导航调整为“首页 / 学习 / 数据 / 我的”。

课程后台提供 ZIP 批量导入。每个 manifest 项通过 Emby Item ID 精确匹配当前课程课时，并且必须同时包含 UTF-8 全文 `transcript.txt` 和 Markdown 摘要 `summary.md`。全包校验通过后在一个事务内写入；任意错误整包回滚；重复上传覆盖旧内容。

新增 `lesson_study_contents` 保存每集全文和摘要，新增 `GET /api/v1/lessons/{lessonId}/study-content` 只读接口。追加 V013 将可复用的历史转写片段合并为全文，将历史全局摘要迁入新表，然后删除聊天、转写任务、FTS、分段摘要和其他 AI 表。用户接受删除已有聊天记录。

运行时外部服务配置只保留 Emby。环境变量仍作为首次默认值，管理员保存后 SQLite 配置优先且对新请求立即生效。

## 后果（Consequences）

- 服务端构建、镜像、配置和运维链路明显缩小，不再持有 LLM、ASR 或 MCP 密钥。
- 课程全文和摘要的生成质量、模型选择与成本由仓库外流程负责。
- 后台导入成为课程内容进入系统的唯一入口，必须保证全包校验和事务原子性。
- V1 移动端暂时不提供 AI 问答；只读学习内容接口为后续 Flutter 能力提供稳定输入。
- 历史聊天记录被删除；可复用的历史全文和全局摘要尽量保留。
- ADR-0004 的服务端只读 AI 决策不再适用；ADR-0006 仅保留 Emby 运行时配置部分。

## 被否决的方案（Rejected Alternatives）

- 保留服务端 AI 但默认关闭：仍需维护依赖、配置、密钥和安全边界，不符合完全移除目标。
- 只删除 UI、保留服务端接口：会留下无人使用且持续增加维护成本的运行能力。
- 后台逐集粘贴全文和摘要：操作效率低，容易出现只更新一半的内容。
- 导入时逐集提交：失败时会形成部分成功状态，不满足整包原子性。
- 重新引入对象存储或向量数据库：当前文本规模可由 SQLite 承载，超出 V1 需求。
