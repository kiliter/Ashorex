# ADR-0020：同一用户可保存多个考试目标

- 状态：已接受（2026-09-03 产品确认）
- 日期：2026-09-03
- 取代：V1.7「每个用户只能有一个活动考试目标」

## 背景（Context）

备考往往并行多场考试。首页只展示一场目标会把其它考试的倒计时和课程压力藏起来。考试设置也必须能分别维护各场考试。

## 决策（Decision）

- 去掉 `exam_goals.user_id` 唯一约束。
- `GET /api/v1/exam-goals` 按考试日期升序返回全部目标。
- `PUT /api/v1/exam-goal` 始终新建；`PUT /api/v1/exam-goals/{id}` 更新当前用户拥有的目标。
- 首页考试卡片用内部 Tab 切换，默认选中到期最近的一场，并展示该场课程进度压力。
- 「我的 → 考试设置」列出全部考试并支持新增、编辑。

## 被否决的方案（Rejected Alternatives）

- 继续覆盖同一行：无法同时跟踪多场考试。
- 用标签字段模拟多考试：进度计算仍绑死一套课程列表。
