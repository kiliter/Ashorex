# ADR-0043：今日还债与统计日期标注

状态：已批准（2026-09-09，用户已确认历史执行和独立统计口径）。

## 决策

今日待办增加「今日还债」分区，直接执行历史未完成的课程、专注和事项，保留原计划日期。今天完成的历史项在本区保留到当天结束；当日新增观看、专注时长和完成数单列，不增加今日计划的分母或完成数。取消历史页及未完成汇总中的顺延到今日、补记完成入口；历史项统一正常执行。旧补记与历史顺延请求由服务端拒绝，旧记录保留展示。

这只是历史任务执行的展示和统计分类，不恢复 V1 债务状态机、惩罚或日终结算。

进度流水保存写入时的计划日期，完成时保存计划日期快照，后续顺延不重新分类。已有数据只能按迁移时可用的计划日期回填，无法还原迁移前的顺延历史。统计总时长继续代表真实学习总量，并明确显示其中还债的观看、专注及完成数。

日图标题显示「今日时段分布（YYYY-MM-DD）」；周柱下分两行显示星期和月/日；月热力格显示日号，完整日期保留无障碍标签。日期均使用服务端返回值。

## 验收

- 历史累计时长不重复计入今日还债，今日计划完成率不变。
- 历史项正常看课、专注、完成后刷新，已完成记录当天仍可见。
- 用户时区跨日按实际事件日期归类，后续顺延保留事件及完成归属。
- 日、周、月可见日期并保留热力图语义标签。

用户追加确认：移除历史待办流转到今日和补记完成逻辑，直接执行原任务。课程添加遇到历史任务时只复用，不改原日期。
